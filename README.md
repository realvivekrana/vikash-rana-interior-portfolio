# Vikash Rana Interior Design Portfolio

Dynamic portfolio website for interior designer Vikash Rana, built on the MERN stack with an admin dashboard.

## Tech Stack
- **Frontend:** React, Vite, Tailwind CSS, React Router, Framer Motion
- **Backend:** Node.js, Express, MongoDB (Mongoose), JWT, Cloudinary

## Structure
- `Frontend/` React app (public site + admin dashboard)
- `Backend/` Express REST API
